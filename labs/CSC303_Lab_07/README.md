# CSC303 — Lab 07: AppBar, Drawer, tabs and themes

**Source:** `CSC303_Mobile_Application_Development_Lab_Manual_Revised_Nov2026.pdf`, pages 38–41.

This shareable archive contains:

- `task_01/`: Worked Task 1 with source files and setup instructions; Lab 01 Task 1 is procedural Git setup.
- `task_02/`: Worked Task 2 with its own source files and setup instructions.
- `CSC303_Lab_07_Manual_Excerpt.pdf`: The corresponding lab pages, including unsolved scenarios, viva questions and extensions.

The two projects are separate examples, because each worked task may replace `lib/main.dart` rather than extend the preceding task. Do not copy one `main.dart` on top of the other.

**Prepare:** Install the Flutter SDK and Android toolchain as explained in Lab 01. Unzip, enter a task directory, and run `bash setup.sh` (Windows users can run it in Git Bash). This creates the generated Android scaffold matching the installed Flutter version, adds Android platform overrides if applicable, and runs `flutter pub get`. Next run `flutter analyze` and `flutter run`. Execute `flutter test` when that task contains real test files.

**Dependency policy:** Package specifications use `any` in this teaching bundle, because the manual records no audited class-wide resolved dependency lockfile. For a class deployment, the instructor should run setup on the selected SDK, validate the results, and commit resulting `pubspec.lock` versions across the portfolio. Do not claim builds are fully reproducible until this is done.

**Do not share:** SSH private keys, access tokens, Firebase service accounts, signing keys, private data or generated cloud credentials.

**Scope:** This contains the complete supplied *worked-example* source, not automatically completed solutions to unsolved scenarios or the independent final semester project.
