# Contributing

1. Create an issue and branch from main.
2. Do not commit credentials, signing keys, SSH private keys, build/ or .dart_tool/.
3. Run dart format, flutter analyze and flutter test when tests exist.
4. Push the feature branch, open a pull request, request a peer review, and address feedback before merging.
5. Provide device screenshot, reviewed PR URL, and commit SHA.

See the exact contribution instructions and shell commands in the attached Lab 01 PDF.
